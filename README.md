# 🌹 Happy Vietnamese Women's Day - 20/10

A beautiful, animated single-page website celebrating Vietnamese Women's Day (Ngày Phụ Nữ Việt Nam - 20/10).

## ✨ Features

- 🌸 Falling flower petals animation
- 💕 Floating hearts effect  
- 🎨 Beautiful rose & gold color palette
- 📱 Fully responsive design
- ✍️ Elegant typography with Google Fonts
- 🎭 Scroll reveal animations
- 💐 Flower gallery with hover effects
- 💬 Inspirational quotes section

## 🚀 Live Demo

Deploy on Vercel or any static hosting to see it live!

## 🛠️ Tech Stack

- HTML5
- CSS3 (Animations, Grid, Flexbox, Glassmorphism)
- Vanilla JavaScript (for dynamic effects)
